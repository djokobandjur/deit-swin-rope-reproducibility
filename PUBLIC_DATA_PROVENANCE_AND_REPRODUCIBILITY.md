# Reproducibility and third-party boundaries — public numerical edition

This 1.0.3 publication candidate is based on the authors' earlier full archived CPU package, with all numeric result tables, A6 source tensor payloads, 14 reference frequency vectors, and model-generated predictions / recorded correctness flags retained. Original image files and ground-truth per-image labels are NOT distributed. Historical model-execution source ZIPs unnecessary to the released CPU arithmetic were omitted; the original author archive remains preserved privately.

ImageNet's official database access terms allow non-commercial research and educational use. This release contains neither ImageNet images nor copies of its original class-label vectors or individual image filenames/synset mappings. Pseudonymous/ordinal cohort indices are authored experiment selectors. It preserves per-image model predictions and original correctness outcomes, which are authors' experimental measurements; these may be used to recalculate accuracy and perturbation damage. It DOES NOT permit users to verify that every recorded correctness outcome equals y_pred==original ImageNet ground truth without their own lawful access to ImageNet.

To verify independent ground-truth correctness, obtain the ImageNet 2012 validation images/labels from an authorized source and compare the experimental index ordering and original SHA-256 label-vector commitment in the JSON metadata; do not redistribute the downloaded labels. SHA commitments attest the source stream but cannot prove labels were accurate without access to the original data.

The original **113/113** research-claim checks and **284/284** supplementary numeric-cell comparisons are reproducible from the provided tabular data. A6 reanalysis regenerates all six tabular outputs from 168 stored PGD delta tensor objects and fourteen F vectors; image-disjoint index audit remains possible. Historical source-code execution and independent GPU evaluation are *not* part of this public edition. The old code-centric historical replay is no longer run; the new public CPU runner checks the remaining numeric sources and derived outputs directly.
