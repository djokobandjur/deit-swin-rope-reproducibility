# Release v1.0.3 — Reproducibility source companion

**Initial public GitHub source companion** to the previously published Zenodo numerical archive.

- **Primary full numerical archive:** https://doi.org/10.5281/zenodo.24055154
- **All-versions Zenodo DOI:** https://doi.org/10.5281/zenodo.24055153
- **Authors:** Đoko Banđur and Miloš Banđur
- **Scope:** 12 author-developed MIT verification/replay scripts, their original tabular summaries (CC BY 4.0), selected evidence/crosswalks and license/citation documentation.
- **Full archived CPU verification:** the separately deposited Zenodo ZIP includes recorded predictions, A6 tensors and 14 F vectors. Its verified numerical analyses include six A6 tables, 113 selected research claims and 284 displayed supplemental table values.
- **Important:** The GitHub tag-source archive is only a small companion: download the **Zenodo ZIP** for complete CPU reproduction. It does not contain ImageNet original annotations, model weights, or historic third-party model execution code.
- **Rights:** MIT applies exclusively to the 12 listed source files; original numerical data/author explanations are CC BY 4.0. Third-party works retain their own rights.

This release reuses the existing Zenodo DOI. **Do not enable automatic GitHub-to-Zenodo release archiving for this companion repository**, as it could create an unintended second Zenodo record.
